# QueryHush

**QueryHush** is a college-exclusive anonymous Q&A platform built under the **EPICS Cohort**.

An anonymous Q&A platform exclusively designed for college students and faculty, built to promote open discussion, doubt clearing, and peer learning — without the fear of judgment.

🏆 **3rd Prize Winner - EPICS Cohort (2025)**  
Organized by [Vishnu Venture Labs Foundation](https://www.linkedin.com/company/vishnu-venture-labs-foundation/) & [Assistive Technology Lab, BVRIT](https://www.linkedin.com/company/assistive-technology-lab-bvrit-n/)
### 🔥 Features

- 🕵️ Anonymous posting system
- ✅ Login/signup using college email
- ⚙️ Admin dashboard to handle reported content
- 🚨 Report system that alerts admins on abuse
- 🔐 Firebase Authentication & Firestore backend
- 🌐 Responsive and interactive frontend (React + Tailwind)

---

### 🛠 Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Firebase (Auth, Firestore, Functions)
- **Deployment**: Firebase Hosting
- **Version Control**: Git & GitHub

---

### 🚀 Getting Started

1. Clone this repo  
   `git clone https://github.com/bhuvncodes/queryhush.git`
2. Navigate to the project  
   `cd queryhushorg`
3. Create your `firebase.js` file from `firebase.example.js` with your config
4. Install dependencies  
   `npm install`
5. Start the app  
   `npm start`
